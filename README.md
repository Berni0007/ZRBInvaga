# ZRBinvaga — режим Invasion для Arma Reforger

Режим Invasion по образцу Squad для модового сервера ZARUBA. Атака берёт точки строго по порядку, взятую точку отбить нельзя. У каждой стороны свой запас тикетов, есть таймер матча.

Дизайн-документ: https://claude.ai/artifact/14bZN9sCMWyX1hpM6NXDwN

**Состояние проекта, план по этапам и инструкция для ИИ-помощника — в [`AGENTS.md`](AGENTS.md).**

## Этап 1 — ядро (скрипты)

| Файл | Что делает |

| `Scripts/Game/ZW_Invasion/ZW_Invasion.c` | Общие помощники |
| `Scripts/Game/ZW_Invasion/ZW_ObjectivesComponent.c` | Фракции атаки и обороны, цепочка точек, победа |
| `Scripts/Game/ZW_Invasion/ZW_TicketsComponent.c` | Тикеты, списание за респаун, бонус за точку |

Настройки задаются в инспекторе компонентов, в категории **Invasion**.

## Расстановка точек в World Editor

1. Перетащите на карту префаб `Prefabs/MP/Modes/CaptureAndHold/Areas/ZW_InvasionPoint.et`.
2. В инспекторе, в категории **Invasion**, задайте:
   - **Order** — порядковый номер в цепочке, 1 = первая цель атаки;
   - **Point Name** — название для HUD;
   - **Capture Seconds** — время захвата (по умолчанию 60);
   - **Min Attackers** — минимум атакующих на точке (по умолчанию 2).
3. В редакторе у каждой точки видны радиус, подпись `#N name [60s, min 2]` и стрелка к следующей точке.
4. **Оранжевый** цвет — всё в порядке, **красный** — ошибка расстановки:
   - `duplicate #N` — два раза один номер;
   - `missing #N` — пропущен номер в цепочке;
   - `order < 1` — номер меньше 1.

Те же ошибки при старте матча пишутся в лог как `[ZW_Invasion] ОШИБКА РАССТАНОВКИ`.

## Отладка

В `ZW_ObjectivesComponent`, категория **Invasion Debug**: `Debug Auto Capture Seconds` — авто-захват текущей точки каждые N секунд без игроков. На боевом сервере держать **0**.

## Правила победы

1. Атака взяла последнюю точку → победа атаки.
2. У обороны кончились тикеты → победа атаки.
3. У атаки кончились тикеты → победа обороны.
4. Вышло время → победа обороны.

## Соглашения

- Префикс всех классов: `ZW_`.
- Состояние считает только сервер, клиентам реплицируются тикеты, таймер и текущая цель.
- Стиль Enforce Script: фигурные скобки на новой строке (Allman).
