# ZRBinvaga — режим Invasion для Arma Reforger

Режим Invasion по образцу Squad для модового сервера ZARUBA. Атака берёт точки строго по порядку, взятую точку отбить нельзя. У каждой стороны свой запас тикетов, есть таймер матча.

Дизайн-документ: https://claude.ai/artifact/14bZN9sCMWyX1hpM6NXDwN

## Этап 1 — ядро (скрипты)

| Файл | Что делает |
| --- | --- |
| `Scripts/Game/ZW_Invasion/ZW_Invasion.c` | Общие помощники |
| `Scripts/Game/ZW_Invasion/ZW_ObjectivesComponent.c` | Фракции атаки и обороны, цепочка точек, победа |
| `Scripts/Game/ZW_Invasion/ZW_TicketsComponent.c` | Тикеты, списание за респаун, бонус за точку |
| `Scripts/Game/ZW_Invasion/ZW_TimerComponent.c` | Подготовка, таймер, бонус времени |
| `Scripts/Game/ZW_Invasion/ZW_InvasionPoint.c` | Точка захвата (наследник `SCR_CaptureAndHoldArea`) |

Настройки задаются в инспекторе компонентов, в категории **Invasion**.

## Правила победы

1. Атака взяла последнюю точку → победа атаки.
2. У обороны кончились тикеты → победа атаки.
3. У атаки кончились тикеты → победа обороны.
4. Вышло время → победа обороны.

## Соглашения

- Префикс всех классов: `ZW_`.
- Состояние считает только сервер, клиентам реплицируются тикеты, таймер и текущая цель.
- Стиль Enforce Script: фигурные скобки на новой строке (Allman).
